Galaxiga

  • Galaxiga is a 2D vertical space shooter (shoot 'em up) built with Unity 6, featuring 70+ handcrafted levels, multiple boss encounters, an endless survival mode, and a full mobile monetization stack. The game is powered by the custom SkyGameKit framework — a battle-tested gameplay layer providing a wave/turn/enemy pipeline, abstract player component system, and object-pooling backbone. Players pilot upgradeable spacecrafts, blast through enemy formations, and confront multi-phase bosses across a campaign that spans the entire history of aerial combat.

  • Key Features:

    • 🚀 70+ Handcrafted Levels: Campaign mode with sequential stages, each hand-designed for unique enemy patterns and increasing challenge.

    • 👾 Boss Encounters: Dedicated boss fights every 5 levels — Eagle Mechanic, Moth, Crab, Star Boss and 10+ more with multi-phase attack patterns.

    • ♾️ Endless Mode: Survival mode with escalating difficulty for high-score competition.

    • ✈️ Multiple Playable Ships: Unlock and upgrade diverse fighter classes, each with unique sprite variants and stat tiers.

    • 🛸 Wingman System: Deploy companion ships that follow the player, providing additional firepower during combat.

    • 🎯 Bullet Hell Combat: UBH (Unity Bullet Hell) driven bullet patterns — dodge complex projectile formations while managing offense.

    • 🌐 Multilingual Support: I2 Localization for multi-language campaigns and global audience reach.

    • 📲 Push Re-engagement: OneSignal push notification campaigns to retain and re-engage players.

  • Technical Architecture (SkyGameKit):

    • 🏗️ Wave Pipeline: LevelManager → SequenceWave / PointWave / FreeWave → WaveManager → TurnManager → BaseEnemy. Three wave types for flexible level design.

    • 🎮 Player Component System: Abstract components (APlayerMove, APlayerAttack, APlayerHealth, APlayerState) — swappable per level or ship variant without code changes.

    • 🔁 Object Pooling: PathologicalGames PoolManager with 3 dedicated pools — EnemyPool, ExplosionPool, BulletPool — for zero-GC gameplay.

    • 💀 Enemy State Machine: InPool → Alive → Dead → Removed lifecycle managed by BaseEnemy with pool-based recycling.

    • 🛤️ Spline Enemy Paths: SWS (Simple Waypoint System) for smooth, spline-based enemy movement patterns and formations.

    • 🦴 Skeletal Animation: Spine runtime for fluid plane and boss animations with multiple animation states.

    • 🔊 Game-Feel Feedbacks: MoreMountains Feel for haptic, audio, and screen-shake feedbacks on hits, explosions, and pickups.

  • Game Modes:

    • 📖 Campaign: 70+ sequential levels (Level6–Level70) with boss checkpoints every 5 stages.

    • 🎓 Tutorial: First-run introductory stages (Level1–Level5) for onboarding new players.

    • 💀 Boss Mode: 14 dedicated boss encounters — LevelBoss1 through LevelBoss14 — for intense skill challenges.

    • ♾️ Endless: Infinite survival with score tracking and escalating wave difficulty.
