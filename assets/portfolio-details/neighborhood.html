Neighborhood Defense

  • Neighborhood Defense is an HTML5 tower defense game exported from Construct 3. Players defend the neighborhood against zombie waves by placing and upgrading different tower types, balancing resources, and reacting to enemy pressure in real time.

  • Key Features:

    • 🧟 Wave Defense Gameplay: Survive incoming enemy waves and protect core structures.

    • 🏹 Multiple Tower Types: Archer, bomb, electric, and sniper towers support different tactical playstyles.

    • 🗺️ Level-Based Progression: Structured stage flow with level data and tower balancing files.

    • 🌐 Browser Ready: Runs directly in web browsers through static hosting.

  • Technical Notes:

    • ⚙️ Exported from Construct 3 with HTML5 runtime, data JSON, and asset bundles.

    • 📦 Includes dedicated tower configuration JSON files for balancing and behavior tuning.

    • 🎵 Uses optimized web media assets (webp/webm) for low-bandwidth delivery.
