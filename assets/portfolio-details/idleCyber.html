    Idle Cyber

    • 2021 — 2022

      Idle Cyber is a cyberpunk idle tower defense game set in a post-apocalyptic 2077 world.

      Players defend the Earth from alien invaders by strategically deploying legendary heroes, upgrading powerful weapons, and customizing gear to survive endless enemy waves and boss battles.

    • My Roles:

      • Worked as Senior Unity Developer, contributing gameplay systems, technical planning, release direction, and implementation quality.

      • Led development of the full gameplay loop including stages, upgrades, rewards, and ad integration.

      • Implemented idle mechanics with strategic tower defense combat.

      • Built a basic NFT marketplace with wallet and testnet blockchain integration.

      • Handled UI/UX, animation integration, and performance optimization for mobile devices.

    • Production Highlights:

      • Fundraising impact: the game successfully raised external funding as an idle defense/GameFi product.

      • Technical leadership: scoped, implemented, shipped, and maintained the core idle defense loop while guiding technical execution.

      • Systems-heavy gameplay: hero collection, stage progression, tower-defense combat, boss waves, offline-style rewards, and upgrade economy.

      • Multi-platform delivery: prepared builds for Android, iOS, and WebGL while keeping UI, input, and performance stable across device classes.

      • Early GameFi prototype: connected Unity gameplay with wallet flow and testnet NFT marketplace concepts before Web3 game tooling matured.

    • Technical Challenges Solved:

      • Balanced idle progression, ad rewards, and tower defense pacing so short sessions still fed long-term upgrades.

      • Kept combat readable under large enemy waves by tuning effects, animation timing, UI feedback, and mobile-friendly resource usage.

      • Separated gameplay economy data from presentation so new heroes, stages, and upgrades could be iterated quickly.
